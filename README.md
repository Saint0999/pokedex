# pokedex
A modern Pokédex web application built using **HTML, CSS, and Vanilla JavaScript**.

This project fetches real Pokémon data from the **PokéAPI** and displays it dynamically in a clean, modern UI. It was built as a practice project to improve skills in API handling, DOM manipulation, and frontend layout design.

A pokemon haven, consisting over 1300+ pokemons. Will be updating later !

## 🚀 Features

- 🔎 Search any Pokémon by name
- 🖼️ Dynamic Pokémon sprite rendering
- 📊 Displays:
  - Name
  - Type
  - Height
  - Weight
  - Ability
- ⚡ Data fetched live using `fetch()` API
- 🎨 Modern responsive UI layout
- 🧠 Nested JSON parsing from external API

## 🛠️ Built With

- HTML5
- CSS3 (Flexbox layout)
- Vanilla JavaScript (ES6+)
- [PokéAPI](https://pokeapi.co/)
