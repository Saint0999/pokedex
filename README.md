# pokedex
A modern Pokédex web application built using vanilla JavaScript, HTML, and CSS.
This project fetches real-time Pokémon data from the PokéAPI and dynamically displays details like sprite, type, height, weight, and abilities. The goal of this project was to practice working with APIs, parsing nested JSON data, manipulating the DOM, and creating a clean responsive UI without any frameworks.
